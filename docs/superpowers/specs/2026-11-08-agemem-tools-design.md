# 社区 Agent 的 AgeMem 工具化记忆设计

用户已批准本工程范围：六类记忆工具与自主调度，强化学习训练另做。复用 Spring AI Alibaba 1.1.2.0 ReactAgent、官方 MessagesModelHook 和现有 MySQL/Milvus 设施，不复现论文训练和指标。

## 行为边界

- ADD、UPDATE、DELETE、RETRIEVE 管理用户长期记忆；SUMMARY、FILTER 管理本轮工作上下文。允许零次记忆调用，不强制每轮先查后写。
- 系统提示规定选择策略，工具描述定义输入输出，后端强制 owner、run/fence/lease、记忆开关、版本和真实原文来源。
- MySQL 正文和不可变版本短事务同步提交，已有投影表写入 PENDING；Embedding/Milvus 由后台 Worker 更新，回答不等待索引。语义查询本身仍需要 query embedding。
- 本轮写入返回准确 before/after epoch，不能随意读最新 epoch 接受并发人工修改；外部删除、修改和关闭记忆仍中止旧回答。
- 一轮唯一有效工作上下文，下一次 ReAct 输入和最终流式回答都消费有效视图。SUMMARY/FILTER 不删除聊天原文，FILTER 不推进持久压缩覆盖游标；更新/删除后的旧版本不可自动复活。
- 保留系统规则、当前完整问题、近期完整问答、完整工具调用和返回配对，以及输入预算和运行时限。
- 临时对话禁持久记忆和历史；关闭记忆仍允许短期上下文管理。先检索站内文章，开启联网至少搜索一次，私有记忆不得流入公开搜索参数。
- 长期记忆写入改由 Agent 决策，回答前必要压缩只生成摘要，不再自动提取事实。旧 PENDING 压缩批次可恢复。
- 最终流式回答、引用校验、SSE 回放、落库与完成事件继续沿用现有链路。

## 验证

验证实际下一轮模型及最终生成请求中的 SUMMARY/FILTER 效果；验证来源、所有者、关闭记忆、临时会话、版本、epoch、自写与外改、异步索引恢复与失败语义；运行受影响回归和可用的真实中间件/模型联调，区分 mock 与实测。

## 简历

代码验证完成后只修改社区项目的记忆条目，保持全黑 B 模板、正文 11pt、严格一页。描述已落地能力，不宣称强化学习训练或论文指标。
