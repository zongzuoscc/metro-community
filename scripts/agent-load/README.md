# Agent 隔离压测客户端

仅针对本机隔离测试服务 `127.0.0.1:18083`；不能直接用于生产或真实用户数据库。

- `mock-model.mjs`：本地 OpenAI 兼容 HTTP 服务，包含标准工具调用往返与约 2 秒真实分段到达的 SSE；不调用外部模型。
- `load.mjs`：使用专属测试 JWT 密钥，依次准备测试用户临时会话与关闭联网设置，按分档同时提交请求，读取 SSE 并校验最终快照。
- `smoke.mjs`：在无其他测试请求时运行，验证首段正文早于上游结束、双读者、越权阻断、事件游标回放、取消关闭上游及临时会话删除隔离。
- 新版冒烟设置 `EXPECT_NATIVE_TOOLS=true`，额外要求合成上游确实观测到标准工具调用与工具结果往返，避免只替换依赖但未接入运行链。
- 测试库需要提前建立 `900001` 起的独立测试账号，服务必须连接独立测试库/Redis，不能共享生产 JWT 密钥。
- `LOAD_OUTPUT` 必填，指定 JSONL 逐请求结果文件；`LOAD_SCENARIOS` 如 `[[50,"temporary"],[50,"persistent"]]`。扩容参数只在隔离服务启动参数生效。
- 不自动重试拒绝请求，不把 HTTP 202 当作成功；只有终态、快照成功且流式正文与保存正文一致才计入成功数。
- 本地合成结果衡量应用接纳、排队、工具调度、SSE 和持久化能力，不代表供应商配额、真实模型质量或生产千路模型并行能力。

客户端默认 JWT 为公开的合成测试密钥，服务启动时必须覆盖 `app.security.jwt-secret` 为同值。无需读取开发 `.env`。

## 混合检索组件并发回归

在后端根目录使用 Java 21 执行：

```sh
./mvnw -Dtest=HybridRetrievalLoadTest test
```

该测试使用一个共享 `HybridArticleRetrievalService`，分别提交 1000 个三路检索请求与
1000 个不触发 HyDE 的两路请求，由测试驱动器限制为 128 个同时执行槽。每个请求使用独立
查询、冻结模型和文章 ID；实际业务检索、HyDE、融合和后处理代码必须保持准确排名、
各路调用次数、旧片段过滤、单篇片段上限，并且不能串用其他请求的模型或结果。

外部数据库、向量和模型接口使用确定性替身，每次模拟 I/O 等待 2ms，不读取配置或真实数据，
也不使用外部 API 额度。输出 `RAG_COMPONENT_LOAD` 包含批次耗时、执行耗时 P95、
执行峰值及调用次数；执行耗时不含等待驱动器槽位的时间，批次耗时包含排队。
这不是 HTTP/SSE 端到端压测，也不是 ES/Milvus/MySQL 或真实模型吞吐认证。
单次 JVM 测试包含类加载/JIT 和框架首次初始化成本，不能仅凭一次快慢宣称吞吐提升。
